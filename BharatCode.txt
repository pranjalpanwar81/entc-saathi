Project: ENTC Saathi
Event: BharatCode Build League (Round 1)
Builder: Pranjal Panwar (GitHub: pranjalpanwar81)
Direction: Learning & education

ENTC Saathi is an AI exam tutor for Electronics & Telecommunication students.
Students can photograph their handwritten answers and get them graded step by
step like a university examiner would. It also explains concepts with solved
numericals, quizzes with marked exam questions, and runs mock vivas, with
university-specific exam styles and an optional Hinglish mode.

BharatCode usage:
- Model: qwen-3.8-27b
- Endpoint: https://bharatcode.ai/api/model/v1/chat/completions
- Features used: streaming responses and image input. Every number is computed
  exactly by the server from calculator tags in a single model call
  (function calling with 8 ENTC tools is also supported: TOOL_MODE=api).
- All model calls go through server.js, so the API key stays on the server.
